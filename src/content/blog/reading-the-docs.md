For years my learning pattern for any new tool was: open a tutorial, copy-paste until something runs, then spend weeks fighting the parts the tutorial hid. At some point I started reading the actual documentation first — the boring reference pages, not the quickstart — and the difference was immediate.

## What actually changes

1. **You learn the mental model, not the incantation.** Tutorials teach sequences of steps. Docs explain what things *are*, which is what you need when the sequence breaks.
2. **You stop fearing error messages.** Half of them reference concepts the docs already introduced.
3. **You find the escape hatches early.** Every tool has a "this is explicitly supported" section that tutorials never mention.

I still use tutorials — but as a guided tour *after* I've read the map, not instead of it.

The irony of writing this as a blog post instead of documentation is not lost on me.
